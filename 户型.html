整体设计详解

📐 模块一：基本参数
占地面积
东西14m × 南北10m = 140㎡
建筑面积
两层共280㎡（一层140㎡+二层140㎡）
卧室数量
一层2间 + 二层4间 = 共6间卧室
卫生间
一层公卫 + 二层主卫 = 共2间（干湿分离）
🚪 模块二：楼梯设计
楼梯走向
一层：入口西侧→北站台→东侧上半
二层：西侧上半→北站台→东侧出口
站台拐角
北侧站台 2.5m×1m | 2.5㎡（南北仅1m，楼梯宽敞）
楼梯分半
西侧/东侧各 1.25m×3.2m = 4㎡（楼梯舒适）
楼梯采光
北边有窗，采光通风好
楼梯总尺寸
2.5m×4.2m | 10.5㎡
🏠 模块三：一层布局详解
北半部分（4.2m）
公卫2.3m×4.2m(干湿分离) + 楼梯2.5m×4.2m + 餐厅5.6m×4.2m + 厨房3.55m×4.2m
走廊
西侧走廊 3.55m×1.6m = 5.7㎡（仅卧室1前保留）
南半部分（4m+1.6m走廊）
卧室1 3.55m×4m + 客厅7m×5.6m + 卧室2 3.55m×4m
入户门
南门中间位置，直通客厅
🏡 模块四：二层布局详解
北半部分（4.2m+1.6m）
主卫2.3m×4.2m(干湿分离+推拉门) + 楼梯2.5m×4.2m + 客厅5.6m×5.8m(开放式) + 次卧3 3.55m×4.2m(东北角)
走廊区域
东西14m × 南北1.6m，与客厅开放式连通
南半部分（4m）
次卧4 3.5m×4m(西南角) + 阳台1.6m×4m + 主卧套房5.4m×4m + 次卧1 3.3m×4m(东南角)
开放式客厅
与走廊无墙无门，空间通透
🪟 模块五：门窗设计
门位置原则
所有门都在侧边（东西侧），避免对视
一层门
公卫门南侧靠东 + 洗澡间推拉玻璃门北侧 + 餐厅西侧门北侧靠北(通往楼梯下) + 餐厅南侧门靠东(厨房侧) + 厨房门东侧 + 卧室1门北侧靠东 + 卧室2门北侧靠西 + 入户门(南门中间)
二层门
主卫门南侧靠东 + 洗澡间推拉玻璃门北侧 + 次卧3门南侧靠西(东北角) + 次卧4门北侧靠东(西南角) + 主卧门北侧靠西 + 次卧1门北侧靠西(东南角)
窗户设计
南向采光窗 + 北向通风窗 + 楼梯北窗
🎯 模块六：功能分区
一层动区
客厅(39.2㎡)+餐厅+厨房+公卫，适合老人和日常活动
一层静区
卧室1+卧室2，无需上楼
二层动区
开放式客厅+阳台，家庭聚会空间
二层静区
主卧套房+次卧1+次卧4+主卫，私密休息空间
